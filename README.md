# fabric-plan-fpna

FP&A budgeting and variance analysis built on **Microsoft Fabric Plan (preview)** — the
Fabric IQ enterprise-planning workload.

**Status: 🚧 in development** — the outline below is the plan; this README grows with
the build.

## Planned build

- Actuals loaded into a **PowerTable** planning model.
- Budget and scenario planning in Planning sheets; variance analysis in Intelligence
  sheets.
- **Writeback** to a Fabric SQL database.
- Plan-vs-actual Power BI report.
- `docs/gotchas.md` — field notes on preview behavior. With a preview workload, the
  honest write-up of what worked and what broke is half the deliverable.
